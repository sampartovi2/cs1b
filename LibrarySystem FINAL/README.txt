# Library management program

## Compilation
 Open a terminal in the directory containing:
 LibrarySystem.cpp, LibrarySystem.h and main.cpp

 Enter "ls" in the terminal to list the files, all 3 should be listed
 Enter "g++ *.cpp" to compile all 3 files
 Enter "./a.out" to display the program output in the terminal

## Usage
    This program is used to simulate a library management system with 
    book, borrower, and transaction information which is entered by the
    user and stored in the database. 

    Enter numbers corresponding to the menu to perform any of the listed functions
    Any changes made should be saved with option 9, the changes will be 
    saved in named .txt files which can later be accessed by the Load data function 
    in the menu. The program can be safely exited and the data will be saved for later use.
